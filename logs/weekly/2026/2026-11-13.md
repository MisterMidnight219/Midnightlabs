## Completed

### Built a segmented Windows training VM on Ellie

**Objective:** Provide an isolated Windows environment for network-defense coursework without placing the training host on the management network.

A Windows 10 VM was provisioned on Ellie with VirtIO storage and networking. The missing network driver was diagnosed, the VirtIO driver media was mounted, and the appropriate Windows network driver was installed. The guest then received the expected addressing, gateway, DNS, and DHCP configuration on the dedicated lab VLAN.

**Evidence label:** Training evidence. The configuration and screenshot were inspected outside the public repository. Live addressing, VM identifiers, and screenshots are excluded from this pull request.

**Evidence reference:** `ellie-windows10-lab-vm-network-verification.png` — sanitized screenshot filename.

**Failure and recovery:** The initial guest had no usable network path because the VirtIO network driver was unavailable to Windows. Mounting the driver ISO and installing the correct architecture-specific driver restored the interface and validated the VLAN path.

**Transferable value:** Another Proxmox operator can reproduce the build by attaching VirtIO driver media during Windows installation, selecting the matching network driver, and verifying DHCP, gateway, and DNS before beginning firewall tests.

### Established an isolated Hermes gateway baseline for AIDA

**Objective:** Run the initial agent gateway with constrained privileges and prove that ordinary web access does not imply access to protected infrastructure.

The Hermes container was deployed on the AIDA host with:

- a digest-pinned amd64 image;
- a dedicated unprivileged runtime identity;
- bounded CPU and memory;
- persistent application data mounted from a dedicated host path;
- zero effective or permitted Linux capabilities;
- `NoNewPrivs` enabled;
- seccomp enforcement;
- no Docker socket;
- no infrastructure credentials; and
- no published dashboard or API ports.

The supervised gateway was verified running. Outbound HTTPS succeeded, while TCP tests to three protected management services failed.

**Evidence label:** Sanitized operational evidence. The tests establish observed reachability from the container; without firewall-log correlation, they do not prove which policy layer caused each failure.

**Evidence reference:** `aida-hermes-gateway-isolation-check-2026-11-13.txt` — sanitized reference to the reviewed terminal record.

**Transferable value:** Another operator can reproduce the pattern by separating agent state, pinning the image, dropping capabilities, denying host-control sockets and credentials, and testing allowed internet access independently from protected network reachability.
