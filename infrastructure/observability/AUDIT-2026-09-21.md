# Observatory Audit — 2026-09-21

## Scope

This audit reconciles work completed after public `main` commit `c51fe67` on 2026-08-30 with the live Observatory deployment and the artifacts proposed for public release.

The private evidence set contained the three Compose layers, central configurations, Prometheus rules, Grafana dashboard, SNMP generator output, and Home Assistant app v0.1.2. Runtime databases, secrets, environment files, backups, logs, and 41 rollback copies were intentionally excluded.

## Findings and remaining work

1. **Public evidence gap — resolved for the central plane.** Public `main` contained no Observatory directory despite the operational deployment. This package establishes the first sanitized central baseline.
2. **Source-side reproducibility remains incomplete.** Custom collectors and local Alloy configuration for several enrolled nodes were not present in the supplied export. They require separate source-host audits before publication.
3. **Domestic-Ops alert annotation mismatch.** `MidnightLabsDomesticOpsRecoverySourceMissing` references label `source`, while the current metric uses `artifact`. Alert evaluation works, but its description can render an empty identifier. The live rule should be corrected and revalidated.
4. **HA dropped-line accounting is currently aspirational.** The app exposes `midnightlabs_ha_log_lines_dropped_total`, but the audited code has no path that increments it. Either implement bounded-buffer/drop detection or remove the misleading signal and alert.
5. **HA Supervisor authorization deserves minimization review.** The add-on requests the `manager` role to read platform and backup state. Confirm the least role that supports every required read-only endpoint.
6. **Container immutability is mixed.** Graphite and SNMP exporters use digest pins; the remaining images use version tags. Decide whether all production images should be digest-pinned and document the update workflow.
7. **Generated SNMP configuration is large but useful.** The generated module is included for reproducibility; third-party MIB files are excluded. Regeneration prerequisites should be documented before changing the module set.
8. **Alert delivery is not yet represented.** Prometheus evaluates policy and Grafana displays it, but this evidence set contains no Alertmanager or external notification route.
9. **Restart history remains visible.** Brief unhealthy timeline segments correctly preserve service recreation events. They are historical telemetry, not current faults.
